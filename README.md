# VELOCITY: Anti-Gravity League (Project Velocity)

An original anti-gravity racing game for Android, built with Godot 4.7 (GDScript, Mobile/Vulkan
renderer). The project owner chose Godot instead of the brief's Unity 6: Unity was not installed and
needs an interactive licence sign-in. See `docs/ARCHITECTURE.md` for the decision and the
Unity-to-Godot mapping. All models, textures and audio are generated by this project's own code.
The only third-party assets are the Orbitron and Rajdhani fonts (OFL, `assets/fonts/`).

## Running

```sh
godot --path .                                   # menus
godot --path . -- --race=helix_bay [--laps=3]    # straight into a race
godot --headless --path . -s tests/run_tests.gd  # unit tests (31)
tools/dev.sh check|test|bench|map <track>        # compile check, tests, handling bench, track map
```

Desktop controls: arrows/WASD steer and thrust, Down/S brake, Q/E airbrakes, V camera, F3 telemetry,
Esc pause. Gamepad: stick, A thrust, B brake, LT/RT analogue airbrakes, Y camera, Start pause.

Automated play test (also `--mode=elimination|combat|speed`, `--career=<event id>`, `--cup=<cup id>`, `--weapon-demo`): `godot --path . -- --race=helix_bay --autopilot --telemetry --laps=1 --shots=/abs/prefix --shot-at=10,30 --quit-on-end [--csv=/abs/file.csv] [--cockpit] [--time-scale=4]`.
On a phone (debug build): `adb shell "run-as com.velocity.agl sh -c 'echo \"--race=helix_bay --autopilot --telemetry\" > files/dev_args.txt'"`, then launch.

## Building

```sh
godot --headless --path . --export-debug "Android" build/android/velocity.apk
adb install -r build/android/velocity.apk
godot --headless --path . --install-android-build-template --export-debug "Android AAB" build/android/velocity.aab
```
A release build needs a release keystore in the Godot editor settings. Regenerate assets with
`python3 tools/gen_textures.py` and `python3 tools/gen_audio.py`.

## Known issues / next steps

- On the A56 the Helix section still runs at 51–56 fps on lap 2. On lap 1 the first sight of new
  materials (tunnel, effects) causes one-off shader-compilation hitches, down to 44 fps.
- The Android emulator cannot present Vulkan frames (VkResult 5), so test on hardware.
- First launch spends about 6 s on shader compilation after a 4.4 s load.
- The AI slides wide in the 35 m Dock Hairpin. The AI pace at PRO difficulty may be too fast for new players.
- Documentation: `docs/ARCHITECTURE.md`, `HANDLING.md`, `ART_DIRECTION.md`, `TRACK_HELIX_BAY.md`,
  `CONTROLS.md`, `PERFORMANCE.md`, `QA_CHECKLIST.md` (each acceptance criterion with its status), `BUILD.md`.
- Weapon balance and AI difficulty with combat on have only been tuned with AI-versus-AI races.
- There is no in-game touch layout editor and no gamepad button remapping.
- Nothing is committed to git yet (repo initialised, no commits).
